## Publishing workflow

1. Read a draft, tweak the voice/details so it's 100% yours, add any specifics you're happy to defend publicly.
2. Post it as a **LinkedIn article** (Profile → Write article).
3. Copy the published URL into the matching entry's `url` in `src/data/content.ts`, and change `date: 'Coming soon'` to the publish date (e.g. `'Jul 2026'`).
4. The Writing card on the site now links straight to the live article.

> Tip: publish one every ~2 weeks rather than all at once — steady cadence beats a burst for LinkedIn reach.
